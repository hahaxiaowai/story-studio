### Task 2：任务名称

- 目标：说明这个任务要交付的最小可验证结果。
- 验收标准：
  - [ ] 具体、可验证的条件。
- 验证方式：
  - [ ] 目标测试、类型检查、构建或人工检查。
- 预计影响文件：
  - `packages/types/...`
  - `packages/utils/...`
- 依赖：Task 1
- 规模：XS / S / M；L 任务必须继续拆分。
- 状态：待确认

任务按可独立验收的用户路径或行为垂直切分，不按页面、状态、API 或测试等纯技术层横向拆分。每项优先控制在 1～5 个文件，但跨 schema、Tauri/Web 或 AI transport 的完整垂直切片可以超过该建议范围。
