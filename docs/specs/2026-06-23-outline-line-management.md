# 大纲线路管理规格

## 背景

当前大纲支持默认主线、新增支线，以及在情节点上勾选所属主线/支线，但不支持编辑线路本身。用户需要在大纲页集中管理线路，主要场景是修改主线或支线名称。

## 目标

- 在大纲页提供“管理线路”入口。
- 支持线路名称、颜色、主线/支线类型和顺序管理。
- 支持新增线路和删除未被情节点引用的线路。
- 保存前使用草稿，取消不落盘。

## 非目标

- 不修改 `WorkspaceOutline`、`PlotLine` 或 `TimelineBeat` 的持久化 schema。
- 不自动迁移或重写已有情节点的线路引用。
- 不新增跨页面全局组件。

## 用户流程

1. 用户进入大纲页，点击右上角更多操作。
2. 用户选择“管理线路”，打开弹窗。
3. 用户在弹窗中修改线路名称、颜色、类型或顺序。
4. 用户可以新增线路。
5. 用户只能删除未被任何情节点引用的线路，且至少保留一条线路。
6. 用户保存后，故事板泳道、情节点卡片和编辑器勾选项同步显示新线路信息。

## 数据模型

继续使用现有字段：

- `WorkspaceOutline.plotLines: PlotLine[]`
- `PlotLine.title`
- `PlotLine.color`
- `PlotLine.kind`
- `PlotLine.order`
- `TimelineBeat.plotLineIds`

删除线路时不修改 `TimelineBeat.plotLineIds`。如果线路被引用，删除操作在 UI 和模型层都被阻止。

## UI 结构

- 大纲页更多菜单新增“管理线路”。
- 管理弹窗为页面私有组件。
- 每条线路显示名称输入、颜色输入、类型选择、删除按钮和拖拽手柄。
- 被引用或最后一条线路的删除按钮禁用，并显示简短原因。

## 技术方案

- 在 outline 模型层新增线路更新、删除、草稿归一化函数。
- 在 `useOutline()` 暴露保存线路草稿的方法。
- 复用现有 `Dialog`、`Input`、`Button` 和 `vue-draggable-plus` 交互模式。
- 补充中英文 locale。

## 验收标准

- 能修改主线和支线名称，并在故事板、情节点卡片和编辑器中同步显示。
- 能修改线路颜色和类型。
- 能拖拽排序并保存顺序。
- 能新增线路。
- 不能删除被情节点引用的线路。
- 不能删除最后一条线路。
- 取消弹窗不保存草稿。
