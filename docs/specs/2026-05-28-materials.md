# 素材库

## 背景

Story Studio 当前已有工作区级的大纲、人物、世界和正文模块。素材收集不应该绑定某个具体工作区，它更像全局资料箱，用来沉淀灵感、参考链接、摘录文字和图片线索，并通过标签进行整理。

## 目标

- 新增全局素材库，不和具体工作区关联。
- 素材包含标题、链接、文字、图片四类可编辑信息，其中链接、文字、图片是核心素材属性。
- 一个素材可以关联多个标签。
- 提供标签管理界面，支持新增、重命名、删除标签。
- 删除标签时，从所有素材中移除该标签引用。
- 素材和标签随本地 Studio 数据一起持久化。

## 非目标

- 不实现工作区内素材引用、素材插入正文或跨模块反链。
- 不实现图片文件上传、Tauri 本地文件复制、缩略图生成或远程抓取。
- 不实现全文搜索、高级筛选、批量导入、批量编辑或云同步。
- 不改变现有工作区级模块的数据归属。

## 用户流程

1. 用户从侧边栏公共功能进入“素材”。
2. 用户查看全部素材，或选择某个标签只看该标签下的素材。
3. 用户新增素材，并填写链接、文字和图片地址中的任意内容。
4. 用户在素材详情里勾选多个标签来分类。
5. 用户打开标签管理界面，新增、重命名或删除标签。
6. 用户删除标签后，该标签从素材标签列表中消失，素材本身保留。

## 数据模型

- `MaterialAsset`：全局素材，包含 `title`、`url`、`text`、`imageUrl`、`tagIds`。
- `MaterialTag`：全局标签，包含 `name`、`color`、`order`。
- `StudioDataDocument.materials`：全局素材集合。
- `StudioDataDocument.materialTags`：全局标签集合。
- `StudioDataDocument.materialRefs`：保留旧字段，本次不接入 UI。

## UI 结构

- `MaterialWorkspace.vue`：素材库主界面。
- 左侧为标签筛选区，包含“全部素材”和标签列表。
- 中间为素材列表，支持新增、选择和删除素材。
- 右侧为素材详情编辑区，包含标题、链接、文字、图片地址和标签选择。
- 标签管理使用同一页面内的管理面板，避免引入新的路由或复杂弹窗。

## 技术方案

- 复用 `useStudioData` 管理持久化。
- 新增 `modules/materials/materials.ts` 放纯数据函数，便于测试。
- 新增 `modules/materials/useMaterials.ts` 接入全局文档状态。
- 将数据 schema 升级到 v6；旧文档迁移时补齐 `materialTags` 并规范化旧素材字段。
- 导航 hash 使用 `#materials`，由首页路由渲染全局素材库，不读取当前工作区。

## 验收标准

- `#materials` 展示全局素材库，而不是工作区概览里的占位素材卡片。
- 新增素材后，素材包含可编辑的链接、文字和图片地址。
- 素材可以同时选择多个标签。
- 标签管理界面可以新增、重命名、删除标签。
- 删除标签会清理所有素材上的对应 `tagIds`。
- v5 文档迁移后包含 `materialTags`，旧素材数据不会丢失。
