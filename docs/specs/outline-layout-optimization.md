# 大纲页布局优化规格

## 背景

当前大纲页已经支持输入模式和编年史模式。编年史模式在桌面端适合横向查看情节点、主线/支线和人物发展，但移动端继续使用二维故事板会产生横向和纵向双轴浏览压力。页头里的英文 `timeline` 也与中文界面不一致。

## 目标

- 提升大纲页的信息层级，让用户先理解当前工作台，再选择浏览或编辑方式。
- 保留桌面端二维故事板，并让右侧轻量编辑器保持可见、独立滚动。
- 移动端使用纵向情节点卡片流，避免横向故事板。
- 保留输入模式作为深度编辑入口，编年史模式用于浏览和轻编辑。
- 让输入模式在桌面端形成独立滚动的双栏工作区，在移动端先展示情节点列表，再进入详情面板编辑。

## 非目标

- 不修改 `WorkspaceOutline`、`TimelineBeat` 或存储 schema。
- 不引入新的 UI 依赖。
- 不重做 Story Studio 品牌视觉或侧边栏导航。

## 用户流程

1. 用户进入 `#outline`，看到紧凑页头、模式切换和新建情节点主操作。
2. 桌面端用户在编年史故事板中横向浏览情节点，点击任意单元格后右侧轻量编辑器更新。
3. 移动端用户在情节点卡片流中纵向浏览，点击卡片打开底部详情面板进行轻编辑。
4. 用户切换到输入模式后，继续编辑当前选中的情节点。
5. 桌面端用户在输入模式左侧切换情节点，右侧详情表单保持独立滚动。
6. 移动端用户在输入模式点击情节点卡片后，通过底部详情面板进行深度编辑。

## 数据模型

复用现有 `WorkspaceOutline` 数据。移动端卡片由编年史模型或输入模式列表模型派生，包含情节点、所属线路、事件数量和人物变化数量。

## UI 结构

- 页头：本地化副标题 + 标题 + 模式切换 + 更多操作 + 新建情节点。
- 桌面编年史：左侧故事板内部滚动区 + 右侧 sticky 轻量编辑器。
- 移动编年史：纵向卡片列表 + 底部 Sheet 轻量编辑器。
- 输入模式：桌面端保留列表与详情表单双栏结构，并让两栏独立滚动；移动端使用纵向情节点列表和底部详情 Sheet。

## 技术方案

- 在 `chronicle.ts` 增加派生移动卡片数据的纯函数。
- 在 `OutlineChronicleMode.vue` 中为移动端新增卡片流，桌面端保留网格。
- 用现有 Sheet 组件承载移动端轻量编辑器。
- 在输入模式中抽出详情表单子组件，复用到桌面右栏和移动端 Sheet。
- 在 `useLocale.ts` 增加必要的中英文文案。

## 验收标准

- 移动端不显示二维故事板，展示纵向情节点卡片。
- 桌面端故事板保留横向滚动，右侧轻量编辑器可独立滚动。
- 切换输入模式和编年史模式时保留选中情节点。
- 输入模式移动端默认不直接展示完整长表单，点击情节点后打开详情 Sheet。
- 输入模式桌面端左侧列表和右侧详情表单可独立滚动。
- 无情节点时仍显示创建入口。
