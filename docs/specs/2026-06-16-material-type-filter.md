# 素材类型筛选

## 背景

素材库已经支持标签筛选和关键词搜索。随着素材同时沉淀摘录、链接和图片地址，用户需要按素材内容类型快速收窄列表，减少在混合素材中查找的成本。

## 目标

- 在素材列表增加类型筛选，支持全部、文字、链接、图片。
- 类型筛选可与现有标签筛选和关键词搜索叠加。
- 不改变 `MaterialAsset` 数据结构，类型从素材字段内容派生。

## 非目标

- 不新增独立素材类型字段。
- 不实现多选类型、排除条件、保存筛选器或高级筛选面板。
- 不改变素材详情编辑、标签管理或持久化格式。

## 用户流程

1. 用户进入素材库。
2. 用户在素材列表区域选择“文字”“链接”或“图片”类型。
3. 素材列表只展示对应字段有内容的素材。
4. 用户继续输入关键词或选择标签时，列表按类型、关键词和标签共同过滤。
5. 用户切回“全部类型”后恢复展示当前标签和关键词范围内的所有素材。

## 数据模型

- 不新增持久化字段。
- `MaterialKindFilter`：前端筛选状态，取值为 `all`、`text`、`link`、`image`。
- 类型命中规则：
  - `text`：`material.text.trim()` 非空。
  - `link`：`material.url.trim()` 非空。
  - `image`：`material.imageUrl.trim()` 非空。

## UI 结构

- 在素材列表搜索框下方增加紧凑的类型筛选按钮组。
- 按钮组包含“全部类型”“文字”“链接”“图片”。
- 当前选中的类型使用与现有标签筛选一致的强调样式。
- 类型筛选按钮显示当前标签和关键词范围内的数量。
- 标签筛选列表显示当前关键词和类型范围内的数量。

## 技术方案

- 在 `modules/materials/materials.ts` 扩展 `MaterialFilterOptions`，由 `getFilteredMaterials` 统一处理 `kind`。
- 在 `useMaterials` 中新增 `selectedKind` 状态，并传给 `getFilteredMaterials`。
- 在 `useMaterials` 中派生 `kindCounts` 和 `tagCounts`，让页面读取统一计数结果。
- 在 `MaterialWorkspace.vue` 中绑定 `selectedKind`，补充中英文文案。
- 使用现有 Vitest 覆盖纯函数、组合式状态和 Vue 文件静态接线。

## 验收标准

- [x] 选择“图片”只展示图片地址字段非空的素材。
- [x] 类型筛选能与标签筛选和关键词搜索同时生效。
- [x] 切回“全部类型”不额外过滤素材。
- [x] 类型筛选数量会随当前标签和关键词变化。
- [x] 标签筛选数量会随当前类型和关键词变化。
