# 世界模块

## 背景

当前工作区包含大纲、人物、地图、内容四个模块，但地图只作为计数和锚点存在。后续创作需要把“地图”提升为“世界”，在同一个世界模块下同时管理世界设定和地图绘制。

## 目标

- 将主导航中的地图模块调整为世界模块。
- 世界模块下提供两个子模块：设定、地图。
- 设定按组组织世界设定，每组包含标题、简介和条目。
- 地图提供首版自由绘制能力，允许用户在世界地图画布上绘制线条并清空重画。
- 世界数据按工作区持久化，并随本地 Studio 数据一起保存。

## 非目标

- 不引入 GIS、瓦片地图或真实地理坐标系统。
- 不实现图层、图标库、图片导入、多人协作或地图导出。
- 不改变大纲、人物、内容模块的数据结构。

## 用户流程

1. 用户从侧边栏进入“世界”。
2. 用户在“设定”中查看按组归档的世界设定，并能新增组和新增条目。
3. 用户切换到“地图”，在画布上自由绘制世界地图草图。
4. 用户绘制或编辑后，数据自动保存到当前工作区。

## 数据模型

- `WorkspaceWorld`：当前工作区的世界数据。
- `WorldSettingGroup`：设定分组，包含 `title`、`description`、`items`。
- `WorldSettingItem`：设定条目，包含 `title`、`body`。
- `WorldMap`：地图文档，首版包含 `strokes`。
- `WorldMapStroke`：一次自由绘制线条，包含颜色、线宽和点集。

## UI 结构

- `WorldWorkspace.vue`：世界模块外壳，负责设定/地图切换。
- `WorldSettingsPanel.vue`：设定分组列表和新增操作。
- `WorldMapCanvas.vue`：地图绘制工具栏和 SVG 画布。

## 技术方案

- 复用现有 `useStudioData` 和 `useWorkspaces` 模式，新增 `useWorld` 组合式逻辑。
- 新增 `world.ts` 作为纯数据操作函数，便于单元测试。
- 将数据 schema 升级到 v4；旧文档没有 `worlds` 时按工作区补默认世界数据。
- 导航 hash 使用 `#world-settings` 和 `#world-map`。

## 验收标准

- 侧边栏顶层显示“世界”，子项为“设定”和“地图”。
- 访问 `#world-settings` 展示当前工作区世界设定。
- 访问 `#world-map` 展示可绘制地图画布。
- 新增设定组、条目和地图笔画会更新当前工作区的世界数据。
- 旧 v3 文档迁移后会拥有 `worlds` 字段。
